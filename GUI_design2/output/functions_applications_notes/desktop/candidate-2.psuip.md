      <text_title>1. Definition of Functions</text_title>
      <text_subtitle>AUDIO TRANSCRIPTION</text_subtitle>
      <text_text>In mathematics, a **function** is a binary relation between two sets that associates every element of the first set to exactly one element of the second set. Typical examples are functions from integers to integers, or from the real numbers to real numbers.</text_text>
    </textCard>
    <confirmableCard>
      <tag>HANDWRITTEN INSIGHT</tag>
      <body>“Think of a function as a machine: you put an "x" in, and exactly one "y" comes out. If you get two different results for the same input, the machine is broken (not a function!)”</body>
    </confirmableCard>

        <text>A function \(f\) is **increasing** on an interval \(I\) if for any two numbers \(x_1\), \(x_2\) in \(I\), \(x_1 &lt; x_2\) implies \(f(x_1) &lt; f(x_2)\).</text>
