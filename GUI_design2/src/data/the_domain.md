# The Domain

Think of it as the "Guest List" for your function. If you're not on the list, you can't get in.

---

## CORE DEFINITION

The complete set of all possible **input values** (usually \(x\)) for which the function is defined.

⏱ Also known as the "Independent Variables".

## The Input-Output Rule

Every function has boundaries. The Domain ensures the math stays "real" and avoids errors like dividing by zero.
