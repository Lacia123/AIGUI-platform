# 固定网格画布模板

Vite + React + TypeScript。离散棋盘网格：固定分辨率画布、组件拖入吸附、碰撞检测。

## 启动

```powershell
cd GUI_design\grid_canvas
npm install
npm run dev
```

浏览器打开终端提示的本地地址（通常是 http://127.0.0.1:5173/）。

## 内置分辨率

| 预设 | 画布像素 | 网格 |
|------|----------|------|
| 手机 | 390×844 | 6×13 |
| 平板 | 768×1024 | 8×12 |
| 桌面 | 1280×800 | 16×10 |
| 方阵 | 800×800 | 10×10 |

切换预设会保留各画布上的独立布局。

## 操作

1. 左侧拖组件到画布
2. 松手后吸附到格点；重叠或越界则不放置
3. 已放置组件可再拖动；双击删除
4. 顶部可切换分辨率；工具栏可开关自适应缩放

## 数据模型

元素：`{ id, type, x, y, w, h }`  
占用：锚点 `(x,y)` + 尺寸 `(w,h)` 覆盖连续矩形格子。
